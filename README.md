day one of learning laravel api
in this session I have covered basic of api
for creating api in laravel we have to install api package first
command= php artisan install:api
after runing this command it will create an api.php at route the api logic were written there


in short this lesson demonstrate how to build an api in laravel <br>
using routes, controllers, models, and http methods like GET, POST, PUT, DELETE<br>
I used Thunder client vs code extension to test this api and they are working fine.
